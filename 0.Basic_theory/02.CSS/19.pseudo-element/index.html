Pseudo Element

1. Pseudo Element

Một số giá trị của pseudo element:

  • ::first-line - Chọn dòng đầu tiên
  • ::first-letter - Chọn chữ cái đầu tiên
  • ::selection - Chọn phần tử vùng đang được bôi đen
  • ::marker - Chọn các điểm đánh dấu của các phần tử
  • ::before - Thêm phần tử vào đằng trước
  • ::after - Thêm phần tử vào đằng sau
