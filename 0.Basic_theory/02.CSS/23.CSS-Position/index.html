CSS Position

Thuộc tính Position cho phép điều chỉnh vị trí các phần tử trên trang web.

1. CSS Position Static vs Relative

CSS Position Static

Đây là giá trị mặc định của position

CSS Position Relative

Định vị so với vị trí ban đầu của nó một khoảng x:

  • left - Cách lề trái ban đầu một khoảng x
  • right - Cách lề phải ban đầu một khoảng x
  • top - Cách lề trên ban đầu một khoảng x
  • bottom - Cách lề dưới ban đầu một khoảng x

Tuy nhiên, không có bất kỳ không gian mới nào được tạo ra để chứa phần tử được định vị theo kiểu này, vì vậy các phần tử khác trong trang web vẫn có thể bị che khuất bởi phần tử được định vị theo kiểu relative
