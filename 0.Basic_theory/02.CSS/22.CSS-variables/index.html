CSS Variables

Khi 1 giá trị css dùng đi dùng lại nhiều lần, ta có thể gán biến cho nó để tái sử dụng

Syntax:

  • Khi khởi tạo, cần khai báo trong :root{} với cú pháp: --tên_biến
  • Khi muốn gọi, truy xuất biến, sử dụng cú pháp: var(--tên_biến)
  • Khi muốn backup, phòng trường hợp giá trị của biến không sử dụng được, sử dụng cú pháp: var(--tên_biến, giá-trị-backup)
